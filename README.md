# destination_bot 🤖

A custom differential drive robot built in ROS2 with A* pathfinding.

## Features
- Custom URDF robot (TurtleBot-style minimal design)
- Gazebo simulation with obstacle world
- SLAM Toolbox for autonomous mapping
- Custom A* pathfinding algorithm
- Easy WASD keyboard controller
- Autonomous explorer node

## Stack
- ROS2 Humble
- Gazebo 11
- SLAM Toolbox
- Nav2
- Python 3
